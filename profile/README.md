# LyX - A Document You Are Writing

![LyX with a short document the user is writing](https://i.sstatic.net/kmXzB.jpg)

## Product Snapshot

LyX is a structured editor aimed at documents you author: headings, math, figures, and citations in a file you save. It can export a PDF when the text is ready. It does not include a library of papers, and it does not remove a restriction from a PDF someone else locked.

Start with a title and one paragraph. Save in a folder you will find after a restart. Compile or export while the file is still small, so the first error is easy to see. The line it names is in your source. Fix that, save, and try again. Do not download a different paper to hide the error.

## Mount and Burn Toolkit

| Task | What you get |
|---|---|
| Outline | Headings of the document you are writing |
| Math | Formulas you enter |
| Figures | Images you made or were allowed to use |
| Citations | Sources you are allowed to reference |
| Export | A PDF from this source |
| Source | The LyX file you keep and edit |

A template is a starting file you have rights to use, saved under your own name. It is not a finished essay.

## Deep Dive

Put figures in the same folder as the document so the paths stay short. If export fails, read the first message before the rest of the log. An unsaved window is not the file the exporter sees. Save first.

A long paste of a chapter you do not have rights to republish is not your document because LyX set the type. Write your own text. Keep the LyX file beside the PDF. The next sentence change happens in LyX, then you export again.

## Adoption Paths

LyX fits a report, a problem set, or a paper you are writing when you want structure and a PDF. It fits a class that asked for that kind of source and gave you a template you may use. It does not fit a locked PDF you want rewritten, and it does not supply the words.

## Install Walkthrough

Prerequisites: A folder for the document, and a TeX setup if export asks for one you still need to install on purpose.

1. Install LyX and create a document in that folder.
2. Type a title and a paragraph. Save.
3. Export or view a PDF and confirm the title.
4. Add one figure you may use, from the same folder.
5. Keep the LyX file after you send the PDF.
